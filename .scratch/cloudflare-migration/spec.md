# Cloudflare 手機記帳移轉

Decision: accepted (2026-11-08)
Implementation: in-progress

## 使用者授權與目標

採 Cloudflare 方案、LINE 提醒，持續月費上限 NT$200。先確認正式專案與資料；舊帳和現有功能全部保留。資料庫、程式語言、架構與套件可優化，不要求沿用 SQL Express/C#。手機記帳要方便、快速。

生活月份 1 號至月底；5 號發薪；7 號信用卡結帳。每月手動匯入銀行資料可接受，其餘自動整理；每次正式月結由本人確認。日常分類剩餘預算立即更新，不做預計收入預測。

## 實作階段

1. 正式來源、一致性備份、完整清冊與逐筆搬移驗證。見 [正式資料基準](../../docs/cloudflare/baseline.md)。
2. 實作快速手機記帳、真實儲存狀態、弱網路防重送與即時分類預算；見 [手機驗收](../../docs/cloudflare/mobile-experience.md)。
3. 移植完整預算/月結/調整/匯入/對帳/投資/查詢能力，以原程式與資料副本作比對依據。
4. 設定 Cloudflare 本人存取、LINE 通知、每日異地備份、7 號排程；先驗證免費用量與恢復能力。
5. iPhone 真機速度和操作驗收、全功能核對與差異報告完成後再切換，原平台保留唯讀。

## 保護條件

- 正式 ERPDB 與原專案不在移轉過程重算、覆寫或退役。
- 不從交易 CSV 補造月結、上限或更正；原有異常原樣保存。
- 原始密碼只在私人舊系統備份保存，雲端使用新的受管登入。
- 私人資料不進 Git、網站資源、公開日誌或測試 fixture。
- 以本機 SQLite 驗證 D1 可攜性時，清楚區分與真實 D1 部署驗證。

## 目前進度

第一階段已完成：正式專案及設定確認；COPY_ONLY 原生備份/還原/CHECKDB；16 表 7,823 列全欄位搬移比對（僅排除雲端密碼）；58 個歷史資產月份一致；既有純計算案例與四項搬移工具測試通過。

新手機網站、雲端部署與 LINE 連接尚未完成，也未替使用者建立任何收費服務。
