# 規格：預算設定與搬錢操作改版（2026-11-20）

Status: ready-for-agent
Created: 2026-11-20
來源：翰陞 2026-11-19 在「改善 App 畫面與操作體驗」說預算相關設定看不出怎麼操作、希望仍圖像化，並點名挪用「從最上面挪到最下面很麻煩」。研究串「研究友善的預算設定操作」做了三個方案的可點原型（[prototype.html](prototype.html)，線上版 https://claude.ai/artifact/BdNFVU39r5NbvZofZxAPS6），翰陞 2026-11-20 選 **A 小罐子牆**。用語見 `CONTEXT.md`「產品（iPhone App）」。

## 背景

PR #40（票 ui-ux-round2/06，draft 未合併）的圖像模式是兩欄大罐子：10 個儲備罐排 5 排、約 3 個畫面高，要按住罐子同時捲畫面才能從「飲食」拖到「其他」；也看不出罐子能拖。設定的「預算與分類」是「先選四種模式（改上限與組別／新增／停用／歸屬）再選分類」的表單，預覽要另外按、再往下捲才看得到。

## 決定

### 搬錢（圖像模式，票 01）
1. 罐子縮小成**一排 4 個**的格子，10 個罐子加錢包在一個畫面內看完；罐子仍以水位表示累積儲備，透支的罐子紅框、金額紅字。
2. 主要操作是**點兩下**：點來源罐子（浮起、外框強調），其他罐子變成可放的樣子，下方出現提示列「從 X 搬出 → 點要放進去的罐子」與「取消」；點目標罐子跳出搬錢面板。再點一次來源＝取消。
3. **按住拖拉保留**作為熟手用法（長按約 0.3 秒拿起）；因為格子一個畫面放得下，拖拉中不需要捲動，拖拉中停用捲動。
4. 錢包是格子上方一整列；只能當來源（補入儲備），不能當目標。餘額 0 或負的罐子不能當來源：晃一下＋`haptics.warning`。
5. 搬錢面板（半高）：上方「來源 → 目標」兩個小罐子與目前金額，罐子對罐子時有「⇄ 對調」；金額大字輸入；快捷鈕「補到 0（X）」（目標透支時才出現，金額＝min(透支額, 來源餘額)）、「全部 X」、「+100」「+1,000」「清除」；超過來源餘額時確認鈕停用並顯示「最多可搬 X 元」。
6. 原因仍必填：提供常用原因標籤（補透支、這個月花比較多、預算調整、買大東西）一按帶入，也可自己打字。
7. 面板內**即時顯示搬完以後**兩邊金額（小字標會計用語「儲備挪用／補入儲備」），按「確認搬 X 元」才生效；不再另外按「預覽」。實作上確認時才依序呼叫 `previewAdjustment` → `confirmAdjustment`（或面板內容變動時 debounce 預覽），帳本服務不改。
8. 下方「最近搬錢」唯讀紀錄照 PR #40。
9. 罐子超過 16 個時格子改成 5 欄或縮小字，仍維持一個畫面；不做分頁。

### 預算與分類（設定頁，票 02）
10. 改成**依組別分組的清單**（儲備類、固定支出、照實支），每組標題旁一句白話說明（沒花完的會存進罐子／回到當月盈餘／花多少算多少）。
11. 最上方卡片：「每月上限合計」與一條**彩色分段長條**＋圖例，看出上限怎麼分配；照實支不在長條內。
12. 點分類開**編輯面板**：名稱、組別（三段分段按鈕）、每月上限（＋／− 每次 500、滑桿 0～20,000 每格 100、也可直接輸入）、「記帳時這些分類算在這裡」標籤（＝交易分類歸屬，「＋ 加入」選尚未歸屬到此的交易分類）、常用原因標籤＋自由輸入、面板內即時顯示前後差異、「儲存」；最下方紅字「停用這個分類…」（儲備類會要求選剩餘儲備轉入的罐子）。
13. 每組最後一列「＋ 新增 X 分類」，組別預先帶好。
14. 「其他」名稱與組別鎖定，面板只能改上限，並說明原因（ADR 0007）。
15. 頁面下方保留上限版本紀錄（可展開）。
16. 圖像／會計模式開關只影響搬錢畫面；新的預算與分類頁兩種模式都用。

## 不變（規則）
- 搬錢只走既有儲備挪用、補入儲備；錢包只能存進罐子；不新增沖銷。
- 上限、組別、歸屬、停用仍從開放月份起生效，每次都要原因；已結月份與 58 個月舊帳不動。
- 帳本服務（`previewAdjustment`／`confirmAdjustment`／`previewBudgetCommand`／`runBudgetCommand`）不改規則、不改數字；只改畫面。若實作發現需要改服務層，先停下來回報。
- 付費權益只管搬錢（票 01）與停用分類：無權益時這兩項唯讀（沿用 `closeEntitlement`）。改上限、改名稱與組別、新增分類、交易分類歸屬維持**免費**（訂閱方案 Q1「預算上限與進度」免費，付費牆文字也這樣寫），不可鎖。

## 不做

- 一次搬多個來源／多個目標。
