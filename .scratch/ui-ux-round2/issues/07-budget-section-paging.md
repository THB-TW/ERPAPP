# 07 — 預算頁區段改成左右翻頁

**Blocked by:** PR #35–#40（第二輪 01–06）先合併，特別是 04（拿掉預算頁「尚未設定預算歸屬」卡）

**Status:** implemented — awaiting iPhone acceptance

**Owner:** `budget-reserve`　**Spec:** [規格](../spec.md) 第 18–22 點
