# 04 — 沒有預算歸屬的分類一律計入「其他」

**What to build:** 支出分類沒有預算歸屬時，預算頁進度與月結都計入儲備類「其他」，不再擋月結；「其他」成為固定分類。見 ADR 0007。

**Blocked by:** 無

**Status:** implemented — awaiting iPhone acceptance

**Owner:** `budget-reserve`；交叉確認 `legacy-migration`（58 個月舊帳與已結月份數字不變）　**Spec:** [規格](../spec.md) 第 9–12 點

- [x] `src/calc/budgetEngine.ts` 月結時找不到歸屬（約第 470 行「尚未設定有效的預算歸屬」）改成計入「其他」；預算頁進度同一規則
- [x] 從開放月份起生效；已結月份快照、58 個月搬遷資料不重算、不改
- [x] 有歸屬的分類照舊；使用者之後指定歸屬就改計到該類別
- [x] 「其他」固定存在：不能刪除、停用、改名，只能改上限；開帳時自動建立；帳本裡若沒有「其他」（舊備份）要能補上並有測試
- [x] 預算頁拿掉「以下支出尚未設定預算歸屬」卡片與 `unmapped` 顯示
- [x] 帳本服務測試：沒歸屬的分類月結成功且計入「其他」、指定歸屬後改計、已結月份不變、「其他」不能停用
- [x] 更新 `.scratch/finance-product/spec.md` 第 8 條「新分類預設照實支」與相關段落，改成本規則

**共同規則**：從最新 `claude/project-thread-xdtlp5` 開分支 `claude/ui2-NN-<slug>`，PR（draft）合回 xdtlp5。畫面照 `apps/mobile/AGENTS.md`「UI 風格」（只用 `theme.ts`、`kit.tsx`、`LargeTitle.tsx`）。驗收前在 `apps/mobile` 跑 `npm test`、`npx tsc --noEmit`、`EXPO_OFFLINE=1 CI=1 npx expo export --platform ios`；規則改動先寫帳本服務層的失敗測試（ADR 0006）。不碰翰陞的私人帳本。

## Comments

2026-11-15：

未歸屬支出從開放月份計入固定儲備「其他」，預算進度與月結共用同一歸屬規則。其他不能停用、改名或改類型，可改上限／被選為歸屬；開帳自建，新增分類預設計入其他。舊備份缺少其他或上限時以相容讀取補齊，下一次業務寫入才持久化；原始匯出與已結快照保持原樣。同步更新產品規格並移除未歸屬警告卡。另修正總額安全整數檢查，避免貸款支出重複計入其他。開帳選擇「計入其他」會明確覆蓋同月既有草稿歸屬，保留原草稿分類；已補服務層 Red → Green 測試。

測試結果：三項指定檢查皆通過；pass 562，0 失敗。詳見[驗證紀錄](../evidence/04/validation.md)。規則變更已經服務層 Red → Green；兩位 reviewer 的具體問題已修正。

服務測試涵蓋未歸屬月結、指定新歸屬、舊快照、缺少其他／上限的舊狀態、開帳新分類、上限安全整數；58 個月合成搬遷回歸全過。未讀寫任何私人帳本。



iPhone 驗收步驟：

1. 使用另建的測試帳本，新增沒有預算歸屬的支出分類並記帳；預算「其他」進度應增加，月結可繼續。
2. 指定該分類歸屬到其他預算組，開放月份改計新組，已結月份金額保持原樣。
3. 預算設定確認「其他」固定存在，不能改名／類型或停用，但能改上限，也可被選為歸屬。
4. 用測試舊備份（缺少其他）還原，確認可正常開啟、計入其他；請勿拿私人原帳作破壞性測試。
