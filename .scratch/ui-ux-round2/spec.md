# 規格：畫面與操作改善第二輪（2026-11-15）

Status: ready-for-agent
Created: 2026-11-15
來源：翰陞 2026-11-15 在「改善 App 畫面與操作體驗」討論串逐題確認（Q1–Q16）。用語見 `CONTEXT.md`「產品（iPhone App）」；規則改變見 `docs/adr/0007-unmapped-categories-count-as-other.md`。

## 背景

翰陞在 iPhone 實測 UI 改版後提出五項改善：明細滑動要有動畫、日期不要手打、明細顯示全部分類、沒設預算的分類一律算「其他」、預算調整要有給記帳新手用的圖像畫面，並把月結撤銷與前期更正另外放。

## 決定

### 明細（票 01、02）
1. 支出／收入左右滑改成**跟手翻頁**：圓餅圖與下方類別列表整塊跟著手指移動，放開後翻到另一頁或彈回；上方「支出／收入」切換鈕同步移動。（Q1）
2. **支出圓餅圖**：有預算歸屬的交易分類各自一塊彩色；沒有預算歸屬的分類與預算的「其他」合成一塊**灰色「其他」**。這個合併只在圓餅圖上。（Q3、Q10）
3. 彩色依金額由大到小，前 7 個用現有 `chartColors`，第 8 個起用同色系淺一階延伸；灰色只留給「其他」。（Q15）
4. **下方列表**一律照記帳的交易分類逐一列出全部分類，不出現合併的「其他」列；拿掉現在「最多幾塊、其餘併成『其他分類』」的做法。（Q3、Q10）
5. **收入頁**照舊：每個收入分類各自彩色，列表列出全部。（Q11）

### 日期（票 03）
6. 貸款「預計結清月份」、投資「期初月份」：App 內月份選擇器（年份左右切換＋12 個月格子）；貸款多一個「未定」選項（現在允許留空、顯示「待補資料」）。（Q2）
7. 投資交易「日期」、總資產核對「餘額日期」：用 iOS 內建日期滾輪。翰陞同意為此新增套件 `@react-native-community/datetimepicker`（以 `npx expo install` 安裝），iPhone 要重新建置。（Q2、Q16）
8. 四個欄位都不再手打，也不再需要格式檢查的錯誤訊息。

### 預算規則（票 04）
9. 沒有預算歸屬的支出分類（例如 11 月的「AI」）**一律計入預算的「其他」**，預算頁進度與月結都照這樣算，從開放月份起生效；已結月份（含 58 個月舊帳）不變。預算頁「以下支出尚未設定預算歸屬」的卡片拿掉。（Q4）
10. 使用者之後在「預算與分類」把該分類指定到別的預算類別，就改計到那裡。（Q4b）
11. 「其他」變成**固定分類**（儲備類）：不能刪除、停用或改名，只能改上限；新使用者開帳時自動建立。（Q4c）
12. 翰陞的 AI 3,598 就算進「其他」，「其他」超支由他用挪用自行搬錢補。（Q14）

### 預算調整（票 05、06）
13. **兩種模式都拿掉「沖銷」**：不能再新增沖銷；挪錯了就反方向再挪一次並寫原因。已存在的沖銷紀錄照常顯示，帳本服務的沖銷計算保留，舊資料才算得對。（翰陞「沖銷調整拿掉」、Q9）
14. 新增設定「月結管理」頁：放「撤銷最近一次月結」與「前期更正」（先選已結月份再填）。月結精靈頁與調整頁上原本的撤銷入口拿掉，只留這一個入口。（Q7、Q12）
15. 設定首頁加開關「調整畫面：圖像（記帳小白）／清單（會計）」，新使用者預設圖像模式。只影響預算調整畫面。（Q5）
16. **會計模式**：維持現在的清單畫面，只剩「儲備挪用」「補入儲備」。
17. **圖像模式**（Q6、Q8、Q13）：
    - 上方「可用餘額」錢包；下方每個使用中的儲備類分類一個存錢罐（兩欄），罐內水位與金額表示累積儲備。固定支出、照實支沒有儲備，不出現。
    - 按住錢包或罐子拖到另一個罐子，放開才跳出視窗填**金額**（預填可搬上限，可用輸入框與 +100／+1,000 調整）與**原因**，確認後生效（錢包→罐子＝補入儲備；罐子→罐子＝挪用）。
    - 超過上限時確認鈕不能按，旁邊顯示「最多可搬 X 元」；餘額 0 的罐子拖不動，會晃一下並震動提示。
    - 下方列出最近的搬錢紀錄，只供查看。
    - 用白話：「搬錢」「存進罐子」；調整紀錄同一筆旁以小字標會計用語（挪用／補入）。

## 不做
- 不改已結月份的任何數字、不改 58 個月舊帳。
- 不刪帳本服務的沖銷計算（只拿掉畫面入口）。
- 圖像模式不放前期更正、撤銷月結（在「月結管理」）。

## 票
01 明細跟手翻頁 → 02 明細圓餅圖顏色與全部分類 → 03 日期選擇器 → 04 未設預算分類計入「其他」 → 05 拿掉沖銷與月結管理頁 → 06 調整模式開關與圖像模式。01–04 可平行；06 接在 05 之後（同一頁）。
