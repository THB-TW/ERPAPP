# 決定備份、換機與舊帳匯入的規則

Type: grilling
Labels: wayfinder:grilling
Status: resolved
Blocked by: 18-local-first-stack

## Question

資料只在手機上，手機遺失或 App 被刪除時如何不丟帳？備份預設走哪裡（iCloud 自動、手動匯出檔案、兩者都有）、多久一次、要不要加密？換新手機如何搬帳？要不要提供完整匯出（CSV／備份檔）讓使用者帶走資料？翰陞的舊帳（SQL Server ERPDB 的 58 個月）要怎麼變成一個檔案、只匯入他自己的手機，且匯入後能證明數字和舊系統一致？

## Answer

2026-11-10 翰陞六題都同意建議：

1. **三層備份**：(a) iCloud 裝置備份自動帶走（資料庫放在會被備份的位置，不放 Caches／tmp）；(b) 設定頁「匯出備份檔」產生整本帳的 SQLite 副本（`backupDatabaseAsync`／`serializeAsync`，不直接複製 `-wal`），經系統分享面板存到「檔案」、iCloud Drive 或 AirDrop；(c) 匯出 CSV，格式與匯入規格相同，可帶走也可再匯入。
2. **頻率**：每次完成月結後提示匯出一次；設定頁顯示「上次備份日期」，超過 35 天未備份發本機通知。自動存到 iCloud Drive 需原生模組，列為第一版之後。
3. **加密**：第一版備份檔不加 App 自己的密碼，靠 iPhone 與 iCloud 的保護；理由是沒有伺服器，忘記密碼即永久失去帳本。之後再評估「選用密碼」。
4. **換機**：支援 iCloud／「快速開始」整機搬移，以及在新手機匯入備份檔。
5. **匯入備份檔**：整本取代、不合併；取代前自動把目前帳本另存一份可復原；要匯入的備份比手機上的帳舊時先警告。
6. **翰陞舊帳搬移**：repo 內提供只給翰陞用的轉換程式（不放進上架 App），在翰陞的 Mac 上讀 2026-11-08 唯讀備份匯出，轉成一個 App 備份檔，私人資料不進 Git；用 AirDrop 傳到 iPhone、以第 5 點匯入；之後依[票 14](14-legacy-acceptance.md)跑 58 個月比對。搬：交易、信用卡明細、月結、上限、調整、投資、帳戶、分類、成員。不搬：舊網站員工帳號、密碼與權限（App 無登入），以及原始 CSV、年度財報等外部檔案（留在私人備份）。
