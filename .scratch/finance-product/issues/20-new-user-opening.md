# 決定新使用者的開帳流程與預算建議算法

Type: grilling
Labels: wayfinder:grilling
Status: resolved
Blocked by: 09-personal-vs-defaults, 08-subscription-plans

## Question

新使用者第一次打開 App 要做什麼？開帳餘額怎麼填、從哪一天起算？匯入的歷史資料要不要補做月結？[票 09](09-personal-vs-defaults.md)定的「有資料用平均開銷建議預算、沒資料用翰陞的預設」具體怎麼算、分類放進哪個預算組？試用與付費牆（[票 08](08-subscription-plans.md)）在開帳流程的哪一步出現？

## Answer

2026-11-11 翰陞同意建議，只改第一個畫面的文字：

1. **第一個畫面**兩個選項：「其他 App 搬家（匯入 CSV）」與「從零開始」。按鈕文字不寫競品名稱；匯入仍支援天天記帳 12 欄 CSV（[票 15](15-positioning.md)）。
2. **開帳日與餘額**：開帳日是某月 1 號，預設本月，可改成上個月；每個帳戶填開帳日當天的餘額（現金、銀行、電子支付、信用卡未繳金額）。開帳日以前的帳只供明細與平均，不做月結。
3. **預算建議**：有匯入資料時，取最近 3 個完整月份（不足 3 個月用現有完整月份）各分類平均支出，進位到百元，逐項讓使用者確認或修改。沒有資料時，用翰陞的分類與組別，金額依使用者填的月收入，按翰陞「各分類占收入比例」縮放。翰陞的預設只作比例與名稱，不帶入任何個人交易（不得成為種子資料）。
4. **分類組別**：與翰陞預設同名的分類照其組別；其他新分類預設「照實支」，使用者可改。
5. **付費牆**：開帳全程免費；第一次按「開始月結」才出現試用（[票 08](08-subscription-plans.md)）。開帳日選上個月的人，匯入後可立刻做第一次月結。
