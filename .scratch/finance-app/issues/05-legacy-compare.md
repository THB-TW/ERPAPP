# 05 — 58 個月比對工具與報告

**What to build:** 翰陞在 Mac 上對轉換出來的帳本檔執行比對工具，得到一份報告：58 個月每項數字與舊系統是否相同，以及用 App 引擎從原始交易重算的逐月差異。

**Blocked by:** 04 舊帳轉換程式

**Status:** done（2026-11-11；真實資料實跑在票 06）

**Owner:** `legacy-migration`（見 `docs/agents/team.md`）　**Spec:** [規格](../../finance-product/spec.md)

- [x] 透過帳本服務的查詢取數字，與來源匯出逐月比對：當月收入、當月盈餘、可用餘額、學費儲備、總儲備金、各分類儲備、上限快照、帳面總資產
- [x] 另比對交易的筆數與金額加總（信用卡明細在票 12、投資在票 20 補上對應的比對）
- [x] 門檻項目任何一項不為 0 差異時，工具以失敗結束並列出月份與欄位；17 個月歷史差異須同額重現
- [x] 重算報告（從原始交易重算 58 個月）只列差異、不影響成功或失敗
- [x] 完整報告寫到私人位置；另產出一份不含金額明細的摘要，可放進 Git
- [x] 自動測試用虛構資料驗證：相同時通過、刻意改一個數字時失敗並指出位置

## Comments

2026-11-11（票 04 完成後）：轉換程式的摘要已列出交易筆數、收入／支出合計、月份數、有歷史差異的月份數；來源驗證共用 `tools/lib/verify-export.mjs`；帳本服務有 `listTransactions(from, to)`、`listBudgetMonths`、`getBudgetMonth` 可讀回。若轉換時用了 `--mixed-flow split`，依分類的比對要把「原名（收入）」併回原名再比。

2026-11-11 完成（legacy-migration agent 實作；四面向審查＋逐項反證，32 項發現中 29 項成立並已處理；修正後再由兩個檢查者驗證；主 thread 驗證）：
- 工具在 `apps/mobile/tools/legacy-compare/`，說明在 `docs/legacy-migration.md`「比對」一節，執行方式 `cd apps/mobile && npm run legacy-compare -- <匯出目錄> <帳本檔> <報告檔> [--manifest-sha256 <雜湊>]`。結束代碼：0 全過、3 門檻有差異、2 輸入或位置問題、1 其他、64 用法。`npm test` 245 個通過、型別檢查通過。只用虛構資料測過，**還沒有碰過真實匯出**。
- 門檻比對的來源：`dbo.Property`（當月收入、可用餘額、學費儲備、總儲備金、帳面總資產、歷史差異）、`dbo.budget`（當月盈餘；最近月份的各分類累計儲備）、`dbo.BudgetCap`（上限快照，只用在原樣帶入的月份），再加來源財務文件的原始 JSON（所有月份、所有欄位），以及帳本服務讀回的整份財務文件必須與來源相同。交易比筆數與金額（總計、收支、分月、分類、帳戶、逐筆）。
- 釘住的預期：有歷史總資產差異的月份數 = 17（基準身分的「歷史資產差異 0」是另一回事：舊表與文件對不上的月數）。
- 不算失敗、但會顯示在結論旁的資訊：獨立舊表沒有資料而只能與來源文件比對的月份數、舊表裡不屬於已結月份的列、BudgetCap 已過時的月份（舊網站不回寫 BudgetCap）。
- 實跑真實資料時先懷疑舊資料本身的差異：最近月份「其他」的累計儲備差額若等於 Property.budget 減累計列十類合計（期初基準差額，報告會加註）；BudgetCap 與文件的差異；沒有 `dbo.budget` 列的月份。
- 重算報告只供參考：逐月以存檔的前一個月為期初單步重算，預期早期月份、沿用前期上限的月份、有手動調整的月份會有差異。
- 尚未涵蓋：信用卡明細（票 12）、投資（票 20）；摘要與報告的結論都有寫。
- 已知未補的小缺口：來源交易欄位格式錯誤的分支、來源 Property/budget 欄位為 null 的預設值沒有專門測試（轉換程式會先擋下壞列）；Ctrl-C 在比對中途通常要等比對跑完才生效；不要同時跑兩個比對；Node 24 未驗（測試在 Node 22）。
- 票 16（PR #6）合併後帳本會多 `ledger_meta` 與 v4：比對工具不寫死版本與資料表清單，已有測試；票 04 的 `convert.test.ts` 那條寫死資料表清單的斷言由 PR #6 一併改。
- 預算頁（PR #9）與之後的月結精靈改到預算引擎：拿到真實舊帳後，要在那些分支上各跑一次這個比對，合併前確認 58 個月數字不變。
