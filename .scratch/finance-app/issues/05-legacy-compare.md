# 05 — 58 個月比對工具與報告

**What to build:** 翰陞在 Mac 上對轉換出來的帳本檔執行比對工具，得到一份報告：58 個月每項數字與舊系統是否相同，以及用 App 引擎從原始交易重算的逐月差異。

**Blocked by:** 04 舊帳轉換程式

**Status:** ready-for-agent

**Owner:** `legacy-migration`（見 `docs/agents/team.md`）　**Spec:** [規格](../../finance-product/spec.md)

- [ ] 透過帳本服務的查詢取數字，與來源匯出逐月比對：當月收入、當月盈餘、可用餘額、學費儲備、總儲備金、各分類儲備、上限快照、帳面總資產
- [ ] 另比對交易的筆數與金額加總（信用卡明細在票 12、投資在票 20 補上對應的比對）
- [ ] 門檻項目任何一項不為 0 差異時，工具以失敗結束並列出月份與欄位；17 個月歷史差異須同額重現
- [ ] 重算報告（從原始交易重算 58 個月）只列差異、不影響成功或失敗
- [ ] 完整報告寫到私人位置；另產出一份不含金額明細的摘要，可放進 Git
- [ ] 自動測試用虛構資料驗證：相同時通過、刻意改一個數字時失敗並指出位置
