# 11 — 月結精靈基本流程

**What to build:** 付費使用者進月結精靈，自動選到開放月份、當月收入自動帶入，進到計算步驟就看到當月盈餘、各類別「上限－實支」與新的儲備，按完成後該月鎖定；預算頁開始顯示累積儲備、可用餘額與帳面總資產；可看歷史月結。信用卡核對與總資產核對在後面兩張票補上，這張先讓流程走得完。

**Blocked by:** 10 預算頁：分組、上限與本月進度

**Status:** done（2026-11-11；程式與自動測試完成，iPhone 畫面待驗收）

**Owner:** `monthly-close`（見 `docs/agents/team.md`）　**Spec:** [規格](../../finance-product/spec.md)

- [x] 精靈自動帶開放月份；當月收入由收入交易加總，唯讀
- [x] 進入計算步驟即顯示月結預覽，不需再按
- [x] 有支出分類沒有預算歸屬時拒絕並指出分類
- [x] 完成月結後該月交易鎖定；沒有自己上限版本的月份沿用最近的版本並寫成該月快照
- [x] 預算頁顯示各儲備類的累積儲備、可用餘額、總儲備金、帳面總資產
- [x] 可查看歷史月結列表與每月快照
- [x] 帳本服務接受「是否有付費權益」的輸入，沒有權益時拒絕月結指令（付費牆畫面在訂閱票）

待 iPhone 實機驗收（使用可拋棄的測試帳本；需已有期初基準與預算設定）：

1. 記入開放月份的收入與支出後開「月結」，確認自動選到開放月份、收入合計正確且唯讀；次月收入不混入。未結束月份顯示等待下個月，不能開始月結。
2. 進入計算頁，確認不用再按計算即可看到當月盈餘、各類上限／實支／增減、新儲備與帳面總資產；信用卡與總資產步驟清楚顯示尚未開放。
3. 有未歸屬支出時確認被拒絕並指出分類；到設定補歸屬後返回，確認可重新預覽。計算頁返回月結、歷史列表返回及根堆疊標題均正常。
4. 預覽後返回記帳修改收入或支出，再進計算頁確認數字刷新；確認對話框先取消，再快速連點完成，應只顯示一次確認並只保存一個月結。
5. 完成後確認備份提醒出現；返回月結的開放月份推進。回記帳檢查已結月新增停用、交易修改／刪除被鎖；強制關閉重開 App，快照仍存在。
6. 開「預算」，確認可用餘額、總儲備金、帳面總資產與各分類累積儲備對應已結月份；切到較舊月份不得顯示較新月份的儲備。
7. 開「歷史月結」與某月快照，確認原始計算、調整後資產、上限／歸屬分開；搬遷缺快照／缺實支時顯示未保存，歷史差額保留。較長分類名稱、大字體與長列表仍能捲動看完。
8. 驗證完成後「查看本月快照」與「返回月結」的導覽，失敗可重試；票 12、13 接上後另驗信用卡差異及總資產差額阻擋，票 22 接上後另驗權益與唯讀。
