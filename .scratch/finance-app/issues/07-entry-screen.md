# 07 — 記帳畫面

**What to build:** 使用者在月曆上點任一天，下方列出那天的交易；按「新增」進入該天的記帳畫面，用內建鍵盤輸入金額、選分類、帳戶、收支別、備註後儲存；也能修改與刪除。畫面依原型第五版。

**Blocked by:** 01 App 骨架：記一筆支出並在月曆看到

**Status:** done（2026-11-11；畫面待翰陞在 iPhone 上驗收）

**Owner:** `ledger-entry`（見 `docs/agents/team.md`）　**Spec:** [規格](../../finance-product/spec.md)

- [x] 首頁是月曆、預設選今天，可切換月份
- [x] 點日期顯示當天交易與「新增」；按新增才進入記帳表單，表單有返回
- [x] 支援收入與支出、備註；成員欄位選填且預設隱藏
- [x] 只能選已存在的分類，不會自動新增
- [x] 可修改與刪除交易；已結月份的交易顯示為鎖定並說明原因
- [x] 帳本服務的對應指令與查詢有測試；畫面由翰陞在 iPhone 上照驗收步驟操作

待實機驗收（票 02 完成後由翰陞操作）：
1. 打開 App 是本月月曆、選在今天；左右箭頭切換月份。
2. 點任一天，下方列出那天的交易；按「新增」才進表單，表單左上可返回。
3. 記一筆支出、一筆收入（含備註），回到月曆後當天金額與列表更新。
4. 點一筆交易，改金額、分類、帳戶、收支別後儲存；再點進去刪除，確認對話框出現、刪除後列表更新。
5. 鍵盤彈出時「儲存」按鈕沒有被蓋住。
6. 底部五個分頁可切換；從表單返回後停在原本的分頁。
7. 已結月份（匯入舊帳後）：那一天「新增」按不下去並有說明；點交易是唯讀並說明原因。
8. 有成員時表單出現「＋ 成員（選填）」，展開後可選、可改回「不指定」。
