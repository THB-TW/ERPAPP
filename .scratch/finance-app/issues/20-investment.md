# 20 — 投資

**What to build:** 付費使用者記台股個股與虛擬貨幣的期初、買進、賣出、配息，手動填市值快照，看到成本、已實現與未實現損益、財產分配；月結的總資產核對自動帶入累計投入淨額。

**Blocked by:** 13 總資產核對

**Status:** ready-for-agent

**Owner:** `investment`（見 `docs/agents/team.md`）　**Spec:** [規格](../../finance-product/spec.md)

- [ ] 可建立台股個股標的（代號、名稱）與一個虛擬貨幣標的
- [ ] 交易類型：期初、買、賣、配息；買賣標示資金來源為帳內或帳外，帳內要指定帳戶並計入該帳戶餘額
- [ ] 台股用移動平均成本，賣出的已實現損益四捨五入（遠離零）到整數，賣光時成本歸零；虛擬貨幣用成本收回法、不認列損益
- [ ] 數量用十進位運算，不用浮點
- [ ] 缺股數、賣超、未知交易類型被拒絕並說明
- [ ] 市值快照手動輸入並保留歷史；不接報價
- [ ] 財產分配中非投資部分先扣掉累計投入淨額
- [ ] 總資產核對自動帶入累計投入淨額（上界為結算月月底）
- [ ] 舊帳轉換程式補上投資資料（標的、期初、交易、市值快照）的搬遷，比對工具補上各標的成本與累計投入淨額的比對
- [ ] 計算有測試，數字與舊系統的算法一致
