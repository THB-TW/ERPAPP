# 18 — 新使用者開帳流程

**What to build:** 新使用者第一次打開 App，選「其他 App 搬家（匯入 CSV）」或「從零開始」，設定開帳日與各帳戶餘額，得到一份建議的預算並逐項確認，然後開始記帳。全程免費。

**Blocked by:** 10 預算頁：分組、上限與本月進度、15 記帳 CSV 匯入與匯出

**Status:** ready-for-agent

**Owner:** `ledger-entry`（見 `docs/agents/team.md`）　**Spec:** [規格](../../finance-product/spec.md)

- [ ] 第一個畫面兩個選項，文字不含競品名稱
- [ ] 開帳日為某月 1 號，預設本月，可選上個月；各帳戶填開帳日餘額（信用卡填未繳金額）
- [ ] 搬家：匯入後依最近 3 個完整月份（不足則用現有完整月份）各分類平均支出、進位到百元建議上限
- [ ] 從零開始：填月收入，依程式內建的預設分類、組別與占收入比例產生上限
- [ ] 預設表只含名稱與比例，不含任何個人交易或金額
- [ ] 與預設同名的分類照預設組別，其他預設照實支；每一項可確認或修改
- [ ] 建立期初基準：可用餘額＝各帳戶開帳餘額合計＋期初投入額，儲備皆為 0
- [ ] 開帳日以前的交易不參與月結、不計入帳戶餘額
- [ ] 預算建議與期初基準有測試
