# 18 — 新使用者開帳流程

**What to build:** 新使用者第一次打開 App，選「其他 App 搬家（匯入 CSV）」或「從零開始」，設定開帳日與各帳戶餘額，得到一份建議的預算並逐項確認，然後開始記帳。全程免費。

**Blocked by:** 10 預算頁：分組、上限與本月進度、15 記帳 CSV 匯入與匯出

**Status:** done（2026-11-11；待 iPhone 實機驗收，預設收入比例暫定）

**Owner:** `ledger-entry`（見 `docs/agents/team.md`）　**Spec:** [規格](../../finance-product/spec.md)

- [x] 第一個畫面兩個選項，文字不含競品名稱
- [x] 開帳日為某月 1 號，預設本月，可選上個月；各帳戶填開帳日餘額（信用卡填未繳金額）
- [x] 搬家：匯入後依最近 3 個完整月份（不足則用現有完整月份）各分類平均支出、進位到百元建議上限
- [x] 從零開始：填月收入，依程式內建的預設分類、組別與占收入比例產生上限
- [x] 預設表只含名稱與比例，不含任何個人交易或金額
- [x] 與預設同名的分類照預設組別，其他預設照實支；每一項可確認或修改
- [x] 建立期初基準：可用餘額＝各帳戶開帳餘額合計＋期初投入額，儲備皆為 0
- [x] 開帳日以前的交易不參與月結、不計入帳戶餘額
- [x] 預算建議與期初基準有測試


## Comments

2026-11-11 完成（程式與自動測試；尚未在 iPhone 實機操作）：

- 新增根堆疊子頁 `apps/mobile/src/app/onboarding.tsx`。首頁先查開帳狀態，未開帳才推入；已有 `opening_date` 或既有月結資料的帳本（含舊帳／還原備份）跳過。未改任何 `_layout.tsx`、設定頁或分頁導覽骨架。
- 第一頁為「其他 App 搬家（匯入 CSV）」與「從零開始」，開帳全程免費。另有既有備份還原的小入口，換機不必先建立新帳。
- 搬家最少步驟：先檢視預設分類；CSV 使用其他名稱時，在同頁明確新增支出／收入分類 → 開啟票 15 的既有 CSV 頁匯入 → 返回設定開帳日與餘額 → 逐項確認預算。不重寫 CSV 解析、拒收或數量式去重。未知分類仍拒收；可返回新增後重匯，已成功的列會略過。開帳專用分類不設開始月份，避免歷史 CSV 被票 10 的分類啟用日拒收。
- 開帳日預設本月 1 日，可選上月 1 日；各帳戶填當天開帳餘額，信用卡未繳金額為負。可進既有帳戶管理新增或修改；返回時管理頁已存的新餘額優先，其他欄位保留尚未提交的輸入。
- 歷史建議採本月以前最近 3 個已完整結束的日曆月份；第一個歷史月份更近時縮短期間，空月與該分類無支出皆算 0，排除本月、收入及轉帳，平均進位百元。沒有完整歷史月份時填月收入，依比例四捨五入到元。畫面明示採用月份，每項組別／上限可改，改後須重新確認，全數確認才可完成。
- `defaults.ts` 新增公開建議表，既有 v1 種子不改，只含名稱、組別與比例，不含個人交易或金額。既有檔案未提供已定比例，已向使用者非同步詢問，目前採可逐項修改的暫定建議：飲食 20%、交通 5%、娛樂 5%、日常用品 5%、醫療保健 3%、服飾 3%、學習 5%、電話網路 3%、其他 5%；水電瓦斯照實支。電話網路為固定支出、其餘有比例者為儲備類；非預設名稱為照實支。這些是本次建議值，不宣稱為使用者已確認的個人比例。
- 帳本服務實作集中 `src/ledger/onboarding.ts`，`index.ts` 只接線。新寫入經 `openLedger` 的共用佇列與 `db.transaction`，日期、各帳戶餘額、`settings.opening_deployed`（期初投入額，預設 0）、前月期初基準與採納預算同筆提交。可用餘額＝帳戶開帳餘額合計＋期初投入額，收入／當月盈餘／儲備／歷史差額皆為 0；新基準非舊帳搬遷月份。預算採納使用票 10 的 add/edit 指令；不改月結引擎。
- 開帳前歷史保留供明細與平均使用；帳戶餘額沿用票 08 的開帳日起算，月結沿用既有月份順序限制。重送完成開帳會拒絕，不會再建立基準。若開帳前已存在晚於所選月份的預算草稿，明確提示選本月開帳，避免改寫既有草稿。

待 iPhone 實機驗收：

1. 用全新測試帳本啟動，確認只有兩個主要開帳選項、文字不含競品名稱、全程沒有付費牆。
2. 選「從零開始」，確認預設本月 1 日，也能選上月 1 日；填各帳戶餘額、信用卡負數與期初投入額，測試負數／整數輸入及鍵盤避讓。
3. 進帳戶管理新增帳戶、修改既有開帳餘額再返回；確認新值採用，其餘未提交輸入保留。
4. 填月收入，查看比例建議；逐項修改組別及上限，確認修改後需重新確認，尚有未確認項時不能完成。
5. 用另一個全新測試帳本選搬家，明確新增合成 CSV 的未知收入／支出分類，進既有 CSV 頁匯入並返回；未知分類拒收後可新增再重匯，不重複新增交易，步驟與輸入仍保留。
6. 匯入涵蓋近 3 個完整月及本月的合成 CSV，確認建議列出採用月份、百元進位；開帳前交易仍在明細，帳戶餘額只納開帳日起的交易。
7. 完成後回到月曆，記一筆交易；重啟 App 不再開帳。檢查返回鍵及側滑手勢不回到開帳表單；既有已開帳帳本也直接進首頁。
8. 從第一頁還原測試備份，返回即跳過開帳；完成開帳後匯出備份再還原，確認餘額與完成狀態保留。
