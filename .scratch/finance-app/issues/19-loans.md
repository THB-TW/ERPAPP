# 19 — 貸款／分期

**What to build:** 付費使用者建立貸款或分期，月結時自動提撥每月繳款並累積成該筆的儲備；記繳款支出時儲備與剩餘本金減少；結清後停止提撥。翰陞的學費儲備變成其中一筆，數字不變。

**Blocked by:** 11 月結精靈基本流程

**Status:** ready-for-agent

**Owner:** `budget-reserve`（見 `docs/agents/team.md`）　**Spec:** [規格](../../finance-product/spec.md)

- [ ] 可建立、修改貸款：名稱、總額、每月繳款、剩餘本金、預計結清月份
- [ ] 月結提撥當月繳款（不足一期提撥剩餘本金），計入當月總開銷並累積成該筆儲備
- [ ] 分類選該筆貸款的支出，在月結時從其儲備扣掉並減少剩餘本金；沒有繳款交易時只累積
- [ ] 剩餘本金為 0 後不再提撥
- [ ] 帳面總資產包含各貸款儲備
- [ ] 既有的學費儲備以資料庫遷移轉成一筆貸款；舊版備份檔匯入時同樣遷移
- [ ] 預算頁「貸款」區顯示進度條、剩餘本金、每月繳款、預計結清月份
- [ ] 測試：只提撥時與原學費儲備逐月數字相同；票 03 的全部案例仍通過
- [ ] 經 legacy-migration agent 確認 58 個月比對在遷移後仍為 0 差異
