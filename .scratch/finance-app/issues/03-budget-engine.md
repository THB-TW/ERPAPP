# 03 — 預算與月結計算規則移植

**What to build:** 帳本服務能執行舊系統的全部預算指令（設定上限、新增與停用類別、分類歸屬、月結、撤銷、前期更正、預算挪用、可用餘額補入儲備、沖銷），結果與舊系統一字不差。這張票沒有畫面，以移植過來的測試案例驗證。

**Blocked by:** 01 App 骨架：記一筆支出並在月曆看到

**Status:** done（2026-11-11）

**Owner:** `budget-reserve`（見 `docs/agents/team.md`）　**Spec:** [規格](../../finance-product/spec.md)

- [x] 純計算的預算引擎是「狀態＋指令 → 新狀態」的純函式，規則與 `CONTEXT.md` 及 ADR 0003、0004 一致
- [x] 財務文件以帶版本號的單一 JSON 文件保存在 SQLite，寫入在同一個資料庫交易內完成
- [x] 舊系統 C# 測試入口的純計算案例全部移植，期望數字照抄並通過（例如前期更正 -700 經撤銷重結後只套用一次、挪用守恆且重送不重做）
- [x] 已結月份的交易不能新增、修改、刪除
- [x] 每個指令帶操作識別碼：同識別碼同內容不重做，不同內容拒絕；原因必填 1 到 300 字
- [x] 帳本服務提供查詢：某月的當月盈餘、可用餘額、各類別儲備、總儲備金、帳面總資產、採用的上限快照
- [x] 經 legacy-migration agent 確認移植未改變任何月結數字的算法
