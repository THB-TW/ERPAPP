# 08 — 帳戶、轉帳與帳戶餘額

**What to build:** 使用者能新增自己的帳戶（現金、銀行、信用卡、電子支付），記帳戶之間的轉帳（繳卡費、領現金、儲值），並看到每個帳戶的餘額。

**Blocked by:** 07 記帳畫面

**Status:** done（2026-11-11；畫面待 iPhone 實機驗收）

**Owner:** `ledger-entry`（見 `docs/agents/team.md`）　**Spec:** [規格](../../finance-product/spec.md)

- [x] 設定可新增、改名、停用帳戶，並設定開帳餘額
- [x] 可記轉帳：轉出帳戶、轉入帳戶、金額、備註；轉帳不算收入或支出，不出現在明細圓餅圖與預算
- [x] 帳戶餘額＝開帳餘額＋開帳日以後的收入－支出＋轉入－轉出；開帳日以前的交易不計入
- [x] 信用卡帳戶餘額為負代表未繳金額
- [x] 以上規則有透過帳本服務的測試

待 iPhone 實機驗收：
1. 設定 → 帳戶管理與餘額，分別新增現金、銀行、信用卡、電子支付；信用卡開帳未繳金額切成負數，儲存後確認負餘額說明。
2. 點帳戶改名、調整開帳餘額、停用再啟用；確認停用帳戶仍在管理列表，新增收支與轉帳選單不再出現，歷史仍可檢視。
3. 記帳月曆選一天 → 新增 → 轉帳，填轉出銀行、轉入信用卡、金額、備註並儲存；確認返回原日期，當日列表顯示轉帳且月曆收支總額不增加。
4. 到帳戶管理確認兩端餘額一減一增、合計不變；再試領現與電子支付儲值。明細圓餅圖、收入與預算不應增加。
5. 點當日轉帳修改金額／帳戶／備註，確認餘額更新；刪除須先確認，刪除後餘額還原。重啟 App 後確認資料仍在。
6. 已設定開帳日的測試帳本：開帳日前交易／轉帳保留在當日列表但不影響餘額；已結月份不能新增、修改或刪除轉帳。
7. 測試同帳戶轉帳、空白、0、小數或負數金額會拒絕；貼上 `1.5` 不可變成 `15`。鍵盤彈出時儲存按鈕可見，返回仍在原本分頁及日期。
