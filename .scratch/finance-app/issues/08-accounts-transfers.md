# 08 — 帳戶、轉帳與帳戶餘額

**What to build:** 使用者能新增自己的帳戶（現金、銀行、信用卡、電子支付），記帳戶之間的轉帳（繳卡費、領現金、儲值），並看到每個帳戶的餘額。

**Blocked by:** 07 記帳畫面

**Status:** ready-for-agent

**Owner:** `ledger-entry`（見 `docs/agents/team.md`）　**Spec:** [規格](../../finance-product/spec.md)

- [ ] 設定可新增、改名、停用帳戶，並設定開帳餘額
- [ ] 可記轉帳：轉出帳戶、轉入帳戶、金額、備註；轉帳不算收入或支出，不出現在明細圓餅圖與預算
- [ ] 帳戶餘額＝開帳餘額＋開帳日以後的收入－支出＋轉入－轉出；開帳日以前的交易不計入
- [ ] 信用卡帳戶餘額為負代表未繳金額
- [ ] 以上規則有透過帳本服務的測試
