# 沒有預算歸屬的支出分類一律計入「其他」

2026-11-15 翰陞決定（`.scratch/ui-ux-round2/spec.md` 第 9–12 點）：支出分類在當月採用的預算歸屬裡找不到對應時，不再擋下月結，而是計入儲備類「其他」；預算頁進度用同一規則。「其他」因此成為固定分類，不能刪除、停用或改名，只能改上限，開帳時自動建立。

原本的做法是月結遇到沒歸屬的分類就中止（`budgetEngine.ts`「尚未設定有效的預算歸屬」），使用者必須先到設定指定歸屬才能月結；記帳與 CSV 匯入又允許新分類，結果是新分類一出現（例如 2026-11 的「AI」）月結就卡住，預算頁另外顯示一張「尚未設定預算歸屬」卡。翰陞的預算本來就有「其他」這個儲備類別，把未歸屬的支出放進去，超支時再用挪用從別的分類搬錢，符合他的使用方式。

已結月份不受影響：已結快照與 58 個月搬遷資料不重算；而且舊規則下凡有未歸屬分類的月份根本結不了帳，所以任何已經成功的月結在新規則下結果相同。這也取代規格「新分類預設照實支」：新分類不另設預算組，在使用者指定歸屬前都算「其他」。

代價是「其他」的儲備可能被意料外的分類吃掉而變負；靠預算頁進度與挪用處理，不另做提醒。明細圓餅圖把沒歸屬的分類和「其他」合成一塊灰色，但列表仍照交易分類逐一列出。
