> 2026-11-11 起草、同日行銷審查修訂。條件：原創、不近似任何現有記帳 App（特別是天天記帳）的名稱或圖示；中文 2–5 字好唸好記，主畫面放得下；能連到「主動規劃預算，不要當月光族」。商店名稱用「〈名稱〉－預算記帳」，副標題放利益句（見 [store-listing.md](store-listing.md)）。
>
> **撞名查證方式與限制**：查證日 2026-11-11，用網路搜尋 apps.apple.com/tw 頁面。本環境連不到 Apple 的搜尋介面（iTunes Search API 被網路設定擋住），所以「未查到」代表網路搜尋沒找到同名頁面，**不等於 App Store 內搜尋確認沒有**。定案前請翰陞在 iPhone 的 App Store（台灣帳號）搜尋名稱一次，並查智慧局商標檢索系統。

## 推薦排序

1. **月底有餘**：直接呼應「不要當月光族」，正面、四字好唸，且與定位句各說一半（名稱講結果、副標題講做法）；未查到同名。
2. **月月有數**：「有數」同時涵蓋預算規劃與月結核對，貼合差異化；風險是開頭與「月月记账」相似（簡體、大陸區）。
3. **帳對了**：最短、最獨特，對應月結精靈；用「－預算記帳」後綴補足「預算」語意。

不推薦：有餘（太短）、月結本、存好預算、新 C。不月光、預算罐因辨識度與近似問題排後。

商店名稱示例：「月底有餘－預算記帳」（9 字，上限 30）
英文／bundle identifier 示例：`tw.<開發者代號>.monthend`（定案後才改 `app.json`，改了就不能再改 bundle id）
